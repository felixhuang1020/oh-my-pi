### 被解析代码的执行路径（已核读源码确认）

阶段 A 构建注册表：
- `create_models()` → `ModelsImpl.__init__`（models.py:311），装配 4 个可注入协作者：`_providers` / `_credentials`(InMemoryCredentialStore) / `_models_store`(InMemoryModelsStore) / `_auth_context`(default_provider_auth_context)，另有 3 个 per-provider dict（`_refresh_generations` / `_refresh_controllers` / `_publication_chains`）。
- `all_providers()` → `builtin_providers()`（providers/all.py:120），按 `types.KNOWN_PROVIDERS` 顺序从 `_PROVIDER_FACTORIES` 造 9 家 provider；每家 = `create_provider(CreateProviderOptions(...))` → `ProviderImpl.__init__`。
- `set_provider(id)`（models.py:328）= `_supersede_provider_refresh(id)`（代次+1 并 abort 旧刷新）+ 按 id upsert。

阶段 B 模型解析：
- `get_model(provider, id)` → `get_models(provider)` → `ProviderImpl.get_models()` → `_current_models()`（models.py:1319）：`_baseline_models`（来自 providers/data/<id>.json）叠加 `_dynamic_models`，按「类型+id」双匹配替换/追加，再按 `is_model_type(m,"chat")` 过滤。

阶段 C 请求：
- `complete_simple` = `stream_simple(...).result()`（**同步取流 + await 结果**，非直接 async 网络调用）。
- `normalize_context`（utils/transcript.py:75）是生成 `TranscriptContext` 的唯一入口且幂等。
- **三层 lazy_stream 嵌套**：ModelsImpl.stream_simple(lazy#1) → ProviderImpl.stream_simple → `_dispatch`/`_api_for` → LazyApi.stream_simple(lazy#2，此处才 `importlib.import_module`) → `openai_responses.stream`(lazy#3)。`forward_stream` 逐层 push 搬运事件。
- `_apply_auth`（models.py:985）是认证注入唯一收口；`resolve_provider_auth`（auth/resolve.py:44）三级优先级 = overrides.api_key > 已存储 credential > 环境变量。
- deepseek 走 **openai-responses** 适配器（providers/deepseek.py），base_url `https://api.deepseek.com`，认证环境变量 `DEEPSEEK_API_KEY`。
- `build_base_options` 用 `clamp_max_tokens_to_context` 把 max_tokens 钳到 `context_window - estimate_context_tokens - 4096`。
- `send_streaming_request`（openai_responses_shared.py:326）非 2xx 抛 `ProviderHTTPError` 交给外层 `retry_provider_request` 决定重试。
- `process_responses_stream` 按 `output_index` 建槽位、按 `item.type` 分流，就地累积 `output.content` 并推事件。
- `done_event` 被 push → `EventStream._settle` 结算 result future（utils/event_stream.py:150）；`result()` 返回可 await 对象而非协程。
